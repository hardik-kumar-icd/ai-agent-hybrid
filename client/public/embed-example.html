Visor AI Chat Widget - Embed Example

How to Embed

Add this code to your WordPress or Magento site:

User Mode (Chat Widget):

<div id="visor-ai-widget"
     data-base-url="YOUR_API_URL"
     data-admin="false">
</div>

<script src="widget.bundle.js"></script>
<script>
  window.VisorAIWidget.initFromElement('#visor-ai-widget');
</script>

Admin Mode (File Upload):

<div id="visor-ai-widget"
     data-base-url="YOUR_API_URL"
     data-admin="true"
     data-token="your-admin-token-here">
</div>

<script src="widget.bundle.js"></script>
<script>
  window.VisorAIWidget.initFromElement('#visor-ai-widget');
</script>
